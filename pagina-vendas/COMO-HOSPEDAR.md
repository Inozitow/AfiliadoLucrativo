# 🚀 Como Hospedar seu Site no Vercel (GRÁTIS)

## Passo a Passo (5 minutos):

### 1️⃣ Acesse o Vercel
- Vá em: **https://vercel.com**
- Clique em **"Sign Up"** (ou "Login" se já tiver conta)
- Pode fazer login com Google, GitHub ou email

### 2️⃣ Faça o Deploy
Após fazer login:

**OPÇÃO A - Arrastar e Soltar (Mais Fácil):**
1. Na página inicial do Vercel, procure por **"Add New..."** → **"Project"**
2. Clique em **"Browse"** ou arraste a pasta `pagina-vendas` inteira
3. Clique em **"Deploy"**
4. Aguarde 30 segundos
5. ✅ **Pronto!** Seu link público aparecerá na tela

**OPÇÃO B - Via GitHub (Recomendado para updates):**
1. Crie um repositório no GitHub
2. Faça upload da pasta `pagina-vendas`
3. No Vercel, clique em **"Import Project"**
4. Conecte seu GitHub e selecione o repositório
5. Clique em **"Deploy"**

### 3️⃣ Seu Site Estará Online
Você receberá um link tipo:
- `https://pagina-vendas-afiliado.vercel.app`

### 🎯 Domínio Personalizado (Opcional)
Se você tiver um domínio próprio (ex: `meusite.com.br`):
1. Vá em **Settings** do projeto no Vercel
2. Clique em **Domains**
3. Adicione seu domínio
4. Configure o DNS conforme as instruções

---

## 📦 Estrutura dos Arquivos
Certifique-se de que a pasta contém:
- ✅ `index.html`
- ✅ `styles.css`
- ✅ `vercel.json`
- ✅ Pasta `assets/` com as imagens
